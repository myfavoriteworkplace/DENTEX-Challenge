# 13. Convert COCO Bounding Boxes to YOLO

DENTEX format:

```
[x,y,width,height]
```

YOLO needs:

```
[x_center,y_center,width,height]
```

Converter:

```python
def coco_to_yolo(box,w,h):

    x,y,bw,bh=box


    return (

    (x+bw/2)/w,

    (y+bh/2)/h,

    bw/w,

    bh/h

    )
```
